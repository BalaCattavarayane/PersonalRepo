# Agriculture

**Summary**: Notes on agricultural technology, remote sensing applications, and field-level data methods.
**Last updated**: 2026-08-24

---

- [agribound](https://github.com/montimaj/agribound): A Python package that automates agricultural field boundary mapping from satellite imagery, combining seven delineation approaches (object detection, semantic segmentation, vision transformers, foundation models, embedding-based clustering, and multi-engine ensembling) and filtering out non-agricultural features using land cover data. Related: [[Remote_Sensing]], [[Machine_Learning]], [[Python]]. Keywords: field boundary delineation, agriculture, satellite imagery, semantic segmentation, vision transformers, foundation models.
