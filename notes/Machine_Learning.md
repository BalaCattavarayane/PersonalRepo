- [Prompting (Hugging Face Transformers docs)](https://huggingface.co/docs/transformers/tasks/prompting#best-practices-of-llm-prompting): Guide to prompt engineering for LLMs. Best practices include using instruction-tuned models, starting with short prompts and iterating, placing instructions clearly, being specific about the desired output format, and leading the model with the start of the expected answer. Also covers few-shot prompting and chain-of-thought techniques. Related: [[Agentic_Coding]].
