# Embeddings

**Summary**: Notes on embedding techniques, representations, and related products, including geospatial/earth embeddings.
**Last updated**: 2026-08-24

---

- [The Technical Debt of Earth Embedding Products](https://cloudnativegeo.org/blog/2026/02/the-technical-debt-of-earth-embedding-products/): Argues that Earth embedding products are fragmented — each uses different file formats, tile schemes, and storage approaches, creating technical debt for downstream users. Notes that continent-scale pixel embeddings can exceed 70 TB and that a lack of standardized cloud-native formats (GeoParquet, COG, Zarr) forces custom integration work per product. Related: [[Remote_Sensing]], [[Data]]. Keywords: earth embeddings, technical debt, cloud-native formats, GeoParquet, COG, Zarr, remote sensing.
